# 阅检AI助手 — 产品需求文档（PRD）

> 版本：v2.0 | 作者：PM Agent | 日期：2026-05-14

---

## 1. 产品定位

微信小程序「阅检AI助手」，面向写作者和学生，提供 AI 率本地检测能力。

## 2. 用户需求（v2.0 新增）

| 用户 | 痛点 | 需求 |
|------|------|------|
| 论文写作者 | 现有检测漏掉部分AI句式 | 更多句式模式覆盖 |
| 内容创作者 | 单句检测准但跨段逻辑不连贯 | 上下文语义一致性检测 |
| 所有用户 | 不同场景检测准确度波动 | 按场景验证并优化准确率 |

## 3. 功能清单

### F1: AI率检测（v1.0 已有）
- 本地引擎：句式指纹 + 统计特征 + 语义分布
- 整体评分（0-96）+ 段落级 + 句子级

### F1.1: 扩展 AI 句式库（v2.0 新增）
- 新增 AI 句式正则匹配模式（≥10 种）
- 新增 AI 高频模板词（≥20 个）
- 句式覆盖按场景拆分：论文类 / 营销类 / 通用类

### F1.2: 上下文语义一致性检测（v2.0 新增）
- 相邻段落间的语义断层检测
- 观点对立 / 论据重复 / 逻辑跳跃 三类语义异常
- 在检测结果中标注语义异常位置

### F1.3: 场景检测准确度提升（v2.0 新增）
- 论文场景：强化学术模板词 / 引用句式检测
- 公众号场景：强化营销收束句 / 情绪模板检测
- 小红书场景：强化感叹体 / 排比结构检测
- 验证方式：每个场景 ≥ 20 条测试用例

## 4. 页面影响

| 页面 | 变更 |
|------|------|
| pages/result/result | 检测结果页新增"语义一致性"卡片 |
| pages/issues/issues | 问题列表新增"逻辑问题"分类筛选 |

## 5. 页面流程

```
首页 ──[检测]──→ 检测结果页
                    ├── 原：AI评分 + 段落风险 + 来源分析
                    └── 新增：语义一致性卡片
                            │
                            ▼
                    问题句子页
                    └── 新增筛选：全部 / 高频迹 / 逻辑问题 / 较低
```

无新增页面，不修改导航流。

## 6. 非功能需求

- 检测响应保持 < 2s（新增的语义检测不超过 500ms）
- 句式库扩展不降低现有检测准确率（回归测试）
- 支持最大 10,000 字符输入不变
